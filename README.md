# 📊 Salary Analysis Dashboard (Power BI)

## 📌 Overview

This project presents an interactive **Salary Analysis Dashboard** built using Power BI to analyze how different skills impact salary across various job roles such as Analyst, Data Engineer, Data Scientist, Manager, Director, and MLE.

The dashboard helps in understanding **which skills drive higher salaries** and supports better career and hiring decisions.

---

## 🎯 Objectives

* Analyze average salary across job roles
* Compare salary impact of key technical skills
* Identify high-paying skill combinations
* Enable interactive exploration using filters

---

## 🛠️ Tools & Technologies

* Power BI (Dashboard & Visualization)
* DAX (Measures & Calculations)
* Power Query (Data Transformation)
* Excel / Dataset (Data Source)

---

## 📊 Dashboard Features

* KPI Card: **Overall Average Salary (101.35K)**
* Role-based filtering (Analyst, Data Engineer, Data Scientist, etc.)
* Skill-based filters:

  * Python
  * Excel
  * AWS
  * Spark
  * R
* Comparative bar charts showing:

  * Salary impact of each skill (Yes vs No)
* Skill ranking chart:

  * Average Salary by Skills

## 📈 Key Insights

### 🔥 1. Cloud & Big Data Skills Drive Highest Salaries

* Professionals with **AWS and Spark** skills earn significantly higher salaries (~110K+)
* Indicates strong demand for **cloud and big data expertise**

---

### 🔥 2. Python Remains a Core High-Value Skill

* Candidates with Python earn noticeably higher than those without it
* Confirms Python as a **must-have skill in data roles**

---

### ⚠️ 3. Excel Has Minimal Salary Impact

* Salary difference between Excel users and non-users is negligible
* Suggests Excel is a **baseline skill**, not a differentiator

---

### ⚠️ 4. R Skill Shows Lower Salary Impact

* Professionals using R show comparatively lower salaries than others
* Indicates **lower industry demand vs Python**

---

### 🔥 5. Skill Combination Matters More Than Single Skill

* High salaries are associated with combinations like:

  * Python + AWS
  * Spark + Cloud skills
* Single skill alone doesn’t maximize earning potential

---

### 📊 6. Salary Distribution Across Skills

* Top skills cluster around **110K–125K range**
* Lower-tier skills drop to ~55K–80K
* Shows a **clear skill-based salary gap**

---

## 💡 Business / Career Impact

* Helps professionals decide **which skills to learn**
* Helps recruiters identify **high-value candidates**
* Enables organizations to **plan compensation strategies**

## 🚀 How to Use

1. Open the `.pbix` file in Power BI Desktop
2. Use top filters to select job role
3. Use right-side slicers to toggle skills (Yes/No)
4. Analyze salary changes dynamically
